Style guide

Every part of the Nephron interface, in one place. Available only while FLASK_DEBUG=1.

Logo

The logo is the two-kidney mark with its flowing line. The file has no wordmark, so wherever the name should be readable (public header, footer, sign-in) the mark is paired with the word "Nephron" as real text. Inside the signed-in app the circular badge sits at the top left. None of them is ever stretched, recoloured or redrawn.

{{ logo_lockup() }} {{ logo_mark() }}

Colour

The palette from the project blueprint. Lavender is pale on purpose: it is a fill with dark text on it. Status colours always come with an icon and words, so colour is never the only signal.

Lavender#E3E2FF. The primary identity colour: highlights, the active state
Lavender strong#D2D0FB. Hover and pressed
Lavender wash#F1F0FF. Soft panels and selected rows
Deep indigo#302B91. The logo mark, strong accents, links
Violet#7D75EE. Graphics only: chart line, ring, dots
Navy#0C0D35. Headings and main text
Navy button#17193F. The dark pill button
Off-white#F6F7FC. The page
White#FFFFFF. Cards
Muted text#5F6892. Secondary text, 5.4:1 on white
Teal / green#0FA287. Low Preliminary Risk (always with words)
Red#D64560. High Preliminary Risk or an error (always with words)
Amber#C97C00. Pending or attention
Gray#8A90B2. Unavailable or inactive
