What is in these files - and what is not

  • Only the predictors: the model's own input columns, as each person answered them.
  • No identity: no name, email, username, id, date or time, and no gender, address or location.
  • No result: the model's own estimate is left out; it is not a fact to learn from.
  • Age {{ age_cap }} or older is written as {{ age_cap }}. Rows are shuffled, so their order says nothing.
  • Only valid screenings exist: every row passed the website's own checks.

Before retraining: each row still needs a confirmed outcome (for example a doctor's diagnosis). These files have none on purpose. Handle them as health data even though they are de-identified, and keep them out of public places.
