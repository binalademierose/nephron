{{ icon_chip('trending-up', 'lavender') }}Why the threshold sits where it does

{% set t = m.tradeoff %} {% if t %}
  • Sensitivity: people with CKD it flags
  • Specificity: people without CKD it leaves unflagged

At the chosen {{ pct(m.metrics.threshold) }} {{ pct(t.at_threshold.sensitivity) }} sensitivity · {{ pct(t.at_threshold.specificity) }} specificity

Lowering the threshold flags more people: more cases are caught, but more false alarms too. Raising it does the opposite.

{% if m.stage == '1' %}

Rule used: Youden's J - the threshold where sensitivity + specificity is highest, a balance between catching cases and avoiding false alarms. Its data is close to balanced (about half with CKD), so the threshold lands near the middle.

{% else %}

Rule used: the highest threshold that still catches at least 98% of people with CKD (recall first). It is so high because this model's scores sit almost entirely near 0% or near 100% - its lab values (eGFR, creatinine, urine ACR) nearly define CKD in its data - so even a high threshold misses few cases.

{% endif %}
